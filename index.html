Frequently asked questions

Quick answers about the Fake Ledger Wallet demo toolkit.

Is this a real Ledger wallet? +
No. Fake Ledger Wallet is a simulation toolkit for security awareness training and phishing demonstrations. It is not affiliated with Ledger, does not connect to real hardware, and cannot hold, send, or receive any cryptocurrency.
What can I use it for? +
It is intended for red teams, security trainers, and educators who need a realistic decoy UI to demonstrate how phishing and social engineering attacks target crypto users. Use it only in controlled, authorized environments.
Does it require an internet connection? +
No. The app is fully offline. All modules — the decoy seed phrase grid, fake balance screen, spoofed device auth prompt, and USB/Bluetooth pairing stubs — run locally with no network calls
